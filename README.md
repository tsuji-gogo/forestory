# forestory (資格合格体験記ブログ)

HTML / CSS / JavaScript を使って構築した、資格試験の合格体験記をまとめたブログです。
自分自身の学習ログとしてだけでなく、これから受験する人の参考になる情報を整理しています。

## 概要
- 資格ごとの合格体験記を掲載
- 学習方法・使用教材・反省点・試験当日の流れなどをまとめています
- スマホでも読みやすいようレスポンシブ対応
- JavaScript による簡易的な UI（メニュー開閉、ページ内移動など）

## 使用技術
- HTML5
- CSS3（Flexbox / Grid / レスポンシブデザイン）
- JavaScript（DOM 操作 / イベント処理）
